# Project media

Screenshots and clips shown on the project cards.

- Put files here, e.g. `media/opengl-sandbox.jpg` and `media/opengl-sandbox.mp4`.
- Reference them from `projects.js`:
  `image: "media/opengl-sandbox.jpg"` and `video: "media/opengl-sandbox.mp4"`.
- Screenshots: 16:9, about 1200 pixels wide, compressed JPG (a few hundred KB max)
  so the page stays fast to load.
- Videos: 10-30 seconds, MP4 (H.264), a few MB max. Sound is not needed; the
  card player is muted. The video only downloads when a reader clicks play.
- Keep names lowercase with hyphens to avoid broken links on GitHub Pages.
